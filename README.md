# 🌙 밤의 타로 (Night Tarot)

재미로 보는 타로 점 웹앱. Vite + React, 이미지 파일 없이 CSS와 이모지로 카드를 그립니다.

**바로 보기: https://noesis01.github.io/tarot/**

`main` 브랜치에 push하면 GitHub Actions가 자동으로 빌드해서 GitHub Pages에 배포합니다 (`.github/workflows/deploy.yml`).

## 실행

```bash
npm i
npm run dev      # http://localhost:5173
```

빌드: `npm run build` → `dist/` (정적 파일, `base: './'`라 어느 경로에 올려도 동작)

## 고를 수 있는 것

**점 치는 방법 (스프레드)**

| 스프레드 | 장수 | 자리 |
|---|---|---|
| 오늘의 한 장 | 1 | 오늘의 메시지 |
| 예 / 아니오 | 1 | 카드의 대답 (예 · 아니오 · 글쎄요) |
| 과거 · 현재 · 미래 | 3 | 과거 / 현재 / 미래 |
| 상황 · 장애물 · 조언 | 3 | 상황 / 장애물 / 조언 |
| 갈림길 | 3 | 지금의 나 / A를 고르면 / B를 고르면 (A·B 이름 입력 가능) |
| 두 사람의 마음 | 5 | 나의 마음 / 상대의 마음 / 지금의 관계 / 걸림돌 / 앞으로 |
| 말굽 | 7 | 과거 / 현재 / 숨은 영향 / 장애물 / 주변의 영향 / 조언 / 결과 |
| 켈틱 크로스 | 10 | 현재 / 가로막는 것 / 목표 / 뿌리 / 지난 일 / 가까운 미래 / 나의 태도 / 주변 환경 / 희망과 두려움 / 최종 결과 |

**카드 종류** — 메이저 아르카나 22장 / 풀 덱 78장 / 마이너 아르카나 56장

**카드 디자인** — 밤하늘 금박 / 빈티지 양피지 / 흑백 판화

**역방향** — 켜면 약 30% 확률로 카드가 거꾸로 나오고 역방향 해석이 적용됩니다.

**고민 주제** — 종합 / 연애 / 일·학업 / 금전. 고른 주제의 운세를 해석에서 강조합니다.

## 해석 구성

- **전체 흐름**: 질문 → 자리 순서대로 카드를 엮은 이야기 → 카드의 기운(정/역 비율, 메이저 비중, 많이 나온 수트) → 주제별 풀이 → 핵심 카드와 조언
- **카드별 풀이**: 한 줄 요약 → 카드 이야기(그림과 상징) → 정/역방향 자세한 해석 → 연애·일·금전운 → 카드의 조언

선택한 설정은 브라우저에 저장되어 다음에 열어도 유지됩니다.

## 구조

```
src/
├─ App.jsx               # step 상태로 화면 전환 (intro → shuffle → pick → reveal → reading)
├─ data/
│  ├─ major.js           # 메이저 아르카나 22장
│  ├─ minor.js           # 마이너 아르카나 56장 (4수트 × 14랭크)
│  ├─ decks.js           # 덱 구성 / 카드 디자인 목록
│  ├─ spreads.js         # 스프레드 정의 + 배치 계산
│  ├─ topics.js          # 고민 주제 (종합/연애/일·학업/금전)
│  └─ details/           # 카드별 상세 해석 (major, wands, cups, swords, pentacles)
├─ lib/
│  ├─ shuffle.js         # Fisher–Yates 셔플, 역방향 랜덤
│  ├─ summary.js         # 스프레드 전체 요약 문장
│  ├─ josa.js            # 한국어 조사(을/를, 이에요/예요 …)
│  ├─ storage.js         # 설정 저장 (localStorage)
│  └─ useWidth.js
├─ components/           # Intro, Shuffle, Deck(카드 고르기), Spread(뒤집기), Reading(해석), Card, Starfield
└─ styles/               # index.css(전역·화면), card.css(카드·플립·셔플)
```

새 스프레드는 `src/data/spreads.js`의 `SPREADS`에 자리(`label`, `hint`, 좌표 `x`/`y`)만 추가하면 화면과 미리보기가 자동으로 맞춰집니다.
